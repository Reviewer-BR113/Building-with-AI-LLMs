Designing prompts

A prompt is the instruction you give the model — and small changes make big differences. In a real app you don't write prompts by hand each time; you design them: reusable, structured, and predictable.

01 · The Idea

Prompts are the steering wheel

The model's behavior is steered almost entirely by the text you give it. That's powerful — and fragile. A well-designed prompt gets reliable results; a sloppy one gets a different answer every time. In applications, prompt design is real engineering.

02 · User vs System Prompts

One sets the rules, the other asks the questions

The system prompt is set once by the app — it defines the AI's role, tone, and rules, and stays constant. The user prompt is what changes with each request. Same system, many users prompts.

▶ SEE HOW THE SYSTEM PROMPT PERSISTS

03 · Prompt Templates

Write it once, reuse it forever

A template is a prompt with blanks. The app fills the blanks with real values at runtime. This gives you the same reliable structure every time, with only the specifics changing.

▶ FILL IN A TEMPLATE — step through it

04 · Structuring for Consistent Outputs

Tell it the shape you want

If your app needs to use the model's answer, that answer must have a predictable shape. A vague prompt returns a different format each time; a structured prompt that specifies the output makes results consistent.

▶ VAGUE vs STRUCTURED — compare the outputs

05 · Multi-Step Prompt Pipelines

Chain small prompts to do big work

Instead of one giant prompt trying to do everything, break the job into steps — each a simple, reliable prompt whose output becomes the next step's input. Small steps are easier to get right and to debug.

▶ RUN A PIPELINE — messy note → tidy checklist

06 · Keep in Mind

Good prompt-design habits

🎭 Set the role

A clear system prompt anchors tone and behavior across every request.

📐 Specify the shape

State the exact output format when the app will parse the result.

🧩 Split big jobs

A pipeline of small prompts beats one prompt trying to do it all.
