Lesson 06 · 🤖 Building with AI

What is an agent?

You've seen AI use tools. An agentic system is one that keeps going on its own — thinking, acting, and checking results in a loop until a goal is met. Let's see what makes it different from ordinary prompting.

01 · The Idea

An agent runs itself, one step at a time

A normal prompt is a single round trip: ask, get an answer, done. An agent is given a goal and then repeats a small cycle — think, act, observe — deciding its own next move each time, until the goal is reached. This intro keeps everything at the concept level; the details come later.

02 · Agentic Loop vs One-Shot Prompting

One pass, or a cycle?

One-shot prompting answers in a single pass — great for simple questions. An agent instead loops: it thinks about what to do, does it, observes the result, and decides whether it's done or needs another round.

03 · Tool-Connected AI

An agent is only as capable as its connections

On its own, an LLM only knows its training and can only produce text. Connect it to tools (to act) and data (to know current, private facts), and it becomes far more capable. The connections are what turn a model into an agent.

▶ CONNECT THE AGENT

04 · MCP — a Standard Plug (concept)

One protocol instead of custom wiring

Connecting an AI to every tool with its own custom code gets messy fast. MCP (Model Context Protocol) is an open standard for these connections — a tool exposes an MCP interface once, and any MCP-compatible AI can use it. Think of it as USB-C for AI tools.

▶ BEFORE vs AFTER A STANDARD
Concept only — you don't need to build MCP to understand it. The idea that matters: a shared standard lets tools and AIs connect without custom glue for every pair.

A real task, one cycle at a time

Let's run the full agent loop on a real question: "Is it going to rain in Paris this afternoon — should I take an umbrella?" The model can't know today's weather, so it must act.

06 · Keep in Mind

Agents are powerful — and slippery

🔁 Loops can run away

An agent can get stuck repeating itself or wander off-task. Cap the number of steps.

💸 Each step costs

Every loop is another model call — more time and money than a single prompt.

🔒 Real actions, real risk

Tools that send email or change data need strict limits and approvals.
