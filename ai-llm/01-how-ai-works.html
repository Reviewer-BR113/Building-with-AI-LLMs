01 · The Big Picture

An LLM is a very good next-word guesser

At its core, a large language model does one thing: given some text, it predicts the most likely next piece of text, over and over, until the answer is complete. Everything else — the app, the prompt wrapping, the memory — is machinery around that single ability. This lesson shows that machinery in motion.

Analogy — think of autocomplete on your phone, but vastly more capable: it doesn't just finish a word, it can continue a whole thought — as long as it's given the right text to continue from.

03 · Internal Prompt Wrapping

The model sees more than your message

Before your text reaches the model, the app wraps it with other instructions. There are usually three layers: a system prompt (the AI's role and rules), hidden instructions (formatting, safety, tools), and your user prompt. All three are combined into one.

04 · How Tools Structure the Prompt

What you type vs what's actually sent

You might type one short sentence, but the app builds a much larger, structured message around it before sending. This is why the same sentence behaves differently in different apps — each app wraps it differently.

05 · Context Injection & Memory

How a chatbot "remembers" earlier messages

Here's the surprise: the model has no memory between requests — each call starts fresh. So how does a chatbot recall your name from earlier? The app re-sends the whole conversation every time. The "memory" is really the app pasting the history back in.

▶ SEE MEMORY WORK — step through a 2-turn chat
Why this matters — the conversation can only grow so long. Models have a context window (a maximum amount of text they can read at once), so very old messages eventually get trimmed — and the model "forgets" them.

06 · Keep in Mind

The mental model to carry forward

🧠 It predicts text

No database lookup, no "understanding" like a human — it generates the most likely continuation.

🎁 It sees the wrapper

Your message is only one layer. System + hidden instructions shape every answer.

🔁 It's stateless

Memory is the app re-sending history — not the model remembering.
