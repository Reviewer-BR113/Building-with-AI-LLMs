Tool & function calling

In Lesson 05 an agent "used a tool." Here's how that works reliably: the model doesn't act itself — it outputs a structured request saying which function to run and with what inputs. Your app runs it and hands back the result.

01 · The Idea

The model asks; your code acts

A model can't actually check the weather or book a table — it only produces text. Function calling turns that text into action: the model emits a precise, machine-readable request ("call bookTable with these values"), and your trusted code carries it out. The model decides what to do; your app decides whether and how.

02 · A Structured Call, Not Prose

From a sentence to a precise request

The key shift: instead of replying "Sure, I'll book that!", the model outputs a structured object naming the function and its arguments — something your code can execute without guessing.

▶ SENTENCE → STRUCTURED CALL

03 · The Round Trip

Call → run → result → answer

The model's structured call goes to your app, which runs the real function and returns the result. The model then turns that result into a friendly reply. Note: the model never runs anything itself — your code is always in the middle.

▶ FOLLOW THE FULL TRIP

04 · Tool Definitions — the Menu

You tell the model what's available

You give the model a menu of functions it may call — each with a name, a description, and its expected inputs. The model reads the request, picks the matching tool, and fills in the arguments. It can only call what you offer.

▶ THE MODEL PICKS FROM THE MENU

05 · Why Structured Beats Free Text

Machine-readable means checkable

A structured call can be parsed and validated before you act — right function? valid arguments? allowed? Free-text intentions can't be executed safely. Structure is what makes tool use dependable instead of a guessing game.

❌ Free text
"Sure, I'll book a table for you!"

Your code can't act on this — no function, no values, nothing to run or check.
✅ Structured call
bookTable(party: 2, time: "19:00")

Parseable, validatable, executable — the app knows exactly what to do.

06 · Keep in Mind

Calling tools safely

✅ Validate the call

Check the function and arguments before running — the model can still pick wrong.

🔒 Least privilege

Only expose safe tools. A "delete everything" function should never be on the menu.

🙋 Confirm risky actions

For anything costly or irreversible, require human approval before executing.
